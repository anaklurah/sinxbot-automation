Konfigurasi Klien & Server
Pengaturan Proxy Pribadi Karyawan

Setiap karyawan dapat menggunakan proxy residential / datacenter masing-masing untuk menjaga keamanan akun dan menghindari deteksi IP massal saat membuka browser login dan otomasi.

Format URL Proxy yang Didukung:
• http://username:password@ip_proxy:port (HTTP dengan otentikasi)
• socks5://username:password@ip_proxy:port (SOCKS5 dengan otentikasi)
• http://ip_proxy:port (IP Whitelist tanpa user/pass)
Pengaturan Bot Telegram Pribadi

Setiap pengguna/karyawan dapat menghubungkan bot Telegram masing-masing agar laporan postingan otomatis dan URL link tayang langsung terkirim secara privat ke bot pribadi Anda.

Dapatkan bot token gratis dari @BotFather di Telegram.
ID akun Anda atau ID Group Telegram tujuan (cek ID Anda via @userinfobot).
